# Matrix Operations Using Operator Overloading in C++

Object Oriented Programming Using C++ - Lab Manual, Ex.No 3 (Chennai Institute of Technology).

A 2x2 `Matrix` class that overloads `+`, `*`, `[]` and `<<`, validated with `assert()` unit tests.

## Build and run

```
g++ -std=c++17 main.cpp -o matrix
./matrix
```
